# 리뷰 루프 기록

- **작성자**: 웹앱 구현 및 개선
- **검증자 에이전트**: 웹앱이 제대로 동작하는지(파싱 정확도, 예외 파일, 엑셀 출력 형식, 오류 처리) 확인
- **평가자 에이전트**: 디자인이 사용자 친화적인지, 사용하기 쉬운지 평가

각 라운드: 현재 버전 → 두 에이전트 피드백 → 작성자가 반영 → 다음 버전. 최대 5라운드.

## v1 — 초기 버전

- 파일 업로드(드래그앤드롭/다중), 헤더 행 자동 탐지, 마켓 자동 판별(스마트스토어/쿠팡/기타)
- 컬럼 동의어 매핑, 상품명+옵션 결합, 전화번호 정규화, 취소/반품 주문 제외
- 미리보기 표, 템플릿 서식(헤더 색 #9BC2E6, 굵게, 테두리, 열 너비)을 재현한 `당일발주_YYYYMMDD.xlsx` 다운로드
- 스크린샷: `docs/screenshots/v1-*.png`

## 라운드 1 피드백 (v1 대상)

### 검증자 — 6/10
> 샘플 기준으로 업로드~다운로드는 정상이고 서식도 템플릿과 정확히 일치. 하지만 실제 스마트스토어 파일은 대부분 암호가 걸려 열 수 없고, 취소·중복 처리가 허술해 잘못 발주될 위험.

| 심각도 | 발견 사항 |
| --- | --- |
| P0 | 비밀번호 걸린 엑셀을 열지 못함 — 영어 오류 메시지만 표시 |
| P1 | 취소 판정 오류 — `주문세부상태=취소요청`은 포함, `취소철회`·`교환재배송`은 잘못 제외 |
| P1 | 같은 파일을 두 번 올리면 이중 발주(4건 → 8건) |
| P1 | 숫자로 저장된 전화번호 복원이 010만 됨 (050x·02·031·070 실패) |
| P1 | 필수값 누락·수량 오류가 조용히 빈칸으로 출력, 누락 항목이 영어 키(phone, address)로 표시 |
| P2 | BOM 없는 UTF-8 / CP949 CSV 한글 깨짐 |
| P2 | 첫 시트만 읽고 헤더는 20행까지만 탐색 |
| P2 | 비동기 예외 처리 누락, 로딩 표시 없음, 초기화 레이스 |
| P2 | 주문자 연락처를 수취인 번호로 잘못 선택, 옵션이 상품명에 부분 포함되면 옵션 누락 |
| P3 | 0바이트/.txt 파일 안내 부정확, 배송메세지 줄바꿈, SheetJS 0.18.5 보안 취약점(CVE-2023-30533, CVE-2024-22363) |

### 평가자 — 5/10
> 흐름은 단순해서 이해하기 쉽지만, 중복·누락 같은 실수를 막아주지 않고 결과를 고칠 수 없으며 오류 안내가 불친절해 매일 믿고 쓰기엔 부족.

| 우선순위 | 제안 |
| --- | --- |
| 높음 | 키보드로 파일을 고를 수 없음 (Tab 포커스가 업로드 영역에 가지 않음), aria-live 없음 |
| 높음 | 같은 파일 재업로드 시 경고 없이 합쳐짐, 파일별 빼기 버튼 없음 |
| 높음 | 오류 메시지가 기술 용어이고 해결 방법을 알려주지 않음 (암호 파일, jpg 등) |
| 높음 | 필수 정보가 비어도 그대로 다운로드, 누락 항목이 영어로 노출 |
| 중간 | 제외된 주문이 누구인지 볼 수 없음, 표에 마켓 표시 없음 |
| 중간 | 결과를 고치거나 뺄 수 없음 |
| 중간 | 첫 화면 안내 부족(파일 받는 곳, 이후 단계), 샘플 체험 없음, 모바일 문구 |
| 중간 | 다운로드·초기화 후 알림 없음, 초기화 확인 없음, 파일명 중복 |
| 낮음 | 모바일 표 가로 스크롤 단서 없음 |
| 낮음 | 색 대비 부족(스마트스토어 배지 2.25:1, 회색 버튼), 핵심 숫자 강조 부족 |

### 사용자 추가 요청 (라운드 1 중)
- **품목 선택란**: 수제비, 칼국수, 구포국수, 예산국수, 기장 쪽파, 여수 돌산갓, 청도 미나리, 곡물면 중 체크한 품목만 발주서에 포함. `기타`로 품목 추가 가능.
  (음성 입력의 "고포국수"→구포국수, "예상국수"→예산국수로 해석. 앱에서 이름 변경·삭제 가능)

## v2 — 라운드 1 반영

- **품목 선택**: 기본 8개 품목 칩(품목별 주문 수 표시), 전체 선택/해제, 기타 품목 추가·삭제, `기타(목록에 없는 상품)` 포함 여부, 브라우저에 저장. 상품명에서 가장 길게 일치하는 품목으로 자동 분류.
- **비밀번호 걸린 엑셀**: 비밀번호 입력창 → 브라우저 안(WebCrypto)에서 복호화. 틀리면 다시 입력, 건너뛰기 가능. 비밀번호는 저장하지 않음.
- **취소 판정**: 주문상태·주문세부상태·클레임상태 모두 검사, 취소철회·교환재배송 등은 정상 처리.
- **중복 방지**: 같은 파일(이름+크기) 재업로드 차단 + 상품주문번호/주문번호 기준 중복 주문 자동 제외.
- **제외 주문 확인·되살리기**: `제외된 주문도 보기`, 행마다 제외 사유 표시, 체크박스로 포함/제외 직접 조정.
- **미리보기에서 바로 수정**: 칸을 눌러 편집(Enter 확정, Esc 취소), 빈 칸·오류는 빨간색, 확인 권장은 노란색. 오류 행이 있으면 다운로드 전 확인창.
- **전화번호**: 050x·02·지역번호·070 앞자리 0 복원, 형식이 이상한 번호 표시.
- **파일 읽기**: 모든 시트 중 주문 시트 자동 선택, 헤더 50행까지 탐색, CSV UTF-8/CP949 자동 판별, 파일 종류별 한국어 안내, 파일별 ✕ 빼기, 순차 처리와 로딩 표시.
- **수취인 매핑**: 구매자/주문자 열은 수취인 정보로 쓰지 않음. 옵션 결합 규칙 개선. 배송메세지 줄바꿈 → 한 줄.
- **UI**: 3단계 표시, 파일 선택 버튼(키보드 가능)과 포커스 표시, 파일 받는 곳 도움말, 샘플 데이터 체험, 핵심 숫자 강조, 하단 고정 다운로드 바, 다운로드/초기화 알림과 확인창, 모바일 문구·가로 스크롤 안내, 대비 개선.
- **기타**: 파일명에 시각 추가(`당일발주_YYYYMMDD_HHMM.xlsx`), SheetJS 0.20.3으로 업그레이드, 테스트 6개 → 15개.
