# 리뷰 루프 기록

- **작성자**: 웹앱 구현 및 개선
- **검증자 에이전트**: 웹앱이 제대로 동작하는지(파싱 정확도, 예외 파일, 엑셀 출력 형식, 오류 처리) 확인
- **평가자 에이전트**: 디자인이 사용자 친화적인지, 사용하기 쉬운지 평가

각 라운드: 현재 버전 → 두 에이전트 피드백 → 작성자가 반영 → 다음 버전. 최대 5라운드.

- 미리보기 표, 템플릿 서식(헤더 색 #9BC2E6, 굵게, 테두리, 열 너비)을 재현한 `당일발주_YYYYMMDD.xlsx` 다운로드

## v2 — 라운드 1 반영

- **품목 선택**: 기본 8개 품목 칩(품목별 주문 수 표시), 전체 선택/해제, 기타 품목 추가·삭제, `기타(목록에 없는 상품)` 포함 여부, 브라우저에 저장. 상품명에서 가장 길게 일치하는 품목으로 자동 분류.
- **비밀번호 걸린 엑셀**: 비밀번호 입력창 → 브라우저 안(WebCrypto)에서 복호화. 틀리면 다시 입력, 건너뛰기 가능. 비밀번호는 저장하지 않음.
- **취소 판정**: 주문상태·주문세부상태·클레임상태 모두 검사, 취소철회·교환재배송 등은 정상 처리.
- **중복 방지**: 같은 파일(이름+크기) 재업로드 차단 + 상품주문번호/주문번호 기준 중복 주문 자동 제외.
- **제외 주문 확인·되살리기**: `제외된 주문도 보기`, 행마다 제외 사유 표시, 체크박스로 포함/제외 직접 조정.
- **미리보기에서 바로 수정**: 칸을 눌러 편집(Enter 확정, Esc 취소), 빈 칸·오류는 빨간색, 확인 권장은 노란색. 오류 행이 있으면 다운로드 전 확인창.
- **전화번호**: 050x·02·지역번호·070 앞자리 0 복원, 형식이 이상한 번호 표시.
- **파일 읽기**: 모든 시트 중 주문 시트 자동 선택, 헤더 50행까지 탐색, CSV UTF-8/CP949 자동 판별, 파일 종류별 한국어 안내, 파일별 ✕ 빼기, 순차 처리와 로딩 표시.
- **수취인 매핑**: 구매자/주문자 열은 수취인 정보로 쓰지 않음. 옵션 결합 규칙 개선. 배송메세지 줄바꿈 → 한 줄.
- **UI**: 3단계 표시, 파일 선택 버튼(키보드 가능)과 포커스 표시, 파일 받는 곳 도움말, 샘플 데이터 체험, 핵심 숫자 강조, 하단 고정 다운로드 바, 다운로드/초기화 알림과 확인창, 모바일 문구·가로 스크롤 안내, 대비 개선.
- **기타**: 파일명에 시각 추가(`당일발주_YYYYMMDD_HHMM.xlsx`), SheetJS 0.20.3으로 업그레이드, 테스트 6개 → 15개.

## v3 — 라운드 2 반영

- **숫자 주문번호**: 원래 값(raw)으로 읽어 지수 표기 문제 해결, CSV는 글자 그대로 읽기.
- **중복 판정 완화**: 주문번호가 같고 *다른 파일*에 있을 때만 자동 제외. 같은 파일 안이거나 주문번호가 없으면 빼지 않고 ‘같은 주문이 또 있음(확인)’ 경고만.
- **파일 간 취소 반영**: 어느 파일에서든 취소·반품된 주문번호는 모든 파일에서 제외. 배송중·배송완료·구매확정은 ‘이미 발송’으로 제외.
- **품목 분류 정확도**: 지역명(예산, 구포)·흔한 채소명(쪽파, 미나리)만으로는 분류하지 않음, 상품명 우선·옵션 보조, 여러 품목이 걸리면 ‘품목 확인’ 경고. 행마다 품목을 드롭다운으로 직접 변경.
- **품목 관리 모드 분리**: 평소 칩은 체크만. ‘⚙ 품목 관리’에서 품목 추가·삭제와 키워드 편집. 삭제 시 영향 건수 안내와 [되돌리기]. ‘기타’는 기본 해제.
- **조용한 누락 방지**: ③ 위에 ‘발주서에서 빠진 주문 N건 — 사유별 건수, 체크하지 않은 품목별 건수’ 안내(노란색), 클릭하면 빠진 주문 표시.
- **샘플 분리**: 파일이 있으면 샘플 버튼 숨김, 실제 파일을 올리면 샘플 자동 삭제.
- **화면 길이**: 올린 뒤 업로드 영역을 한 줄(‘+ 파일 추가’)로 축소, 처리 후 ③으로 자동 스크롤, 0건 칩 흐리게.
- **키보드**: 표는 Tab 한 번으로 들어가 방향키로 이동, Enter로 편집/체크/품목 선택. ‘다운로드 버튼으로 바로 가기’ 링크, 확인창 포커스 테두리.
- **표 레이아웃**: 마켓은 N/C 작은 표시, 주소·품목 줄바꿈 허용(데스크톱에서 잘림 없음). 모바일은 주문별 카드, 터치 대상 확대.
- **편집 표시**: 고친 칸에 파란 점과 원래 값 툴팁, 행별 ↺ 되돌리기.
- **안정성**: 전역 처리 큐(비밀번호 창 겹침 방지), 처리 중 초기화 시 결과 폐기, 저장된 품목 목록 검증, 저장 불가 시 안내, 구형 암호는 비밀번호 묻기 전에 안내, 복호화 중 화면 멈춤 완화, `+82` 번호 정규화.
- **기타**: 단계 표시에 ✓와 클릭 이동, `word-break: keep-all`, 알림을 오른쪽 아래로, 문구 말투 통일. 테스트 15개 → 21개.
- 스크린샷: `docs/screenshots/v3-*.png`

- **여러 날 중복 발주 방지**: 다운로드한 주문의 식별값을 SHA-256 해시로만 최근 14일치 브라우저에 저장(주문번호·이름·전화는 저장하지 않음). 다음에 같은 주문번호가 들어오면 ‘지난 발주에 있음 (9/27)’으로 기본 제외하고 노란 안내에 “쇼핑몰에서 발주확인 처리를 했는지 확인” 표시. 주문번호가 없는 파일은 같은 손님의 재주문일 수 있어 빼지 않고 ‘확인 필요’로만. 같은 작업 안에서 고친 뒤 다시 받는 것은 막지 않음. 하단에 ‘발주 기록 지우기’.
- **다운로드 완료 상태**: 하단 바가 ‘✅ 6건 저장됨 · 파일명 [새로 시작] [다시 받기]’로 바뀌고, ‘다음 할 일’(공급처에 보내기 / 쇼핑몰에서 발주확인 처리) 안내. 받은 뒤 내용을 고치면 ‘받은 뒤 내용이 바뀌었습니다 — 다시 받아 주세요’.
- **샘플 구분**: 샘플만 있을 때 하단에 ‘🧪 샘플 데이터입니다’ 띠, 버튼은 ‘샘플 발주서 받아보기’, 파일 이름은 `샘플_당일발주_….xlsx`, 발주 기록에는 남기지 않음. 첫 방문 때는 업로드 영역 안에 ‘처음이라면: 샘플 데이터로 먼저 해보기’ 버튼, 실제 파일을 한 번 쓴 뒤에는 작은 링크로.
- **분류 보강**: 제외 키워드 `-A` 지원(기본: 기장 쪽파에 `-찰기장`, `-기장쌀`), `여수+돌산` 제거(‘돌산갓’으로 충분, 돌산공원 오분류 해소). 갓김치는 판매 품목일 수 있어 기본으로 빼지 않고, 필요하면 품목 관리에서 `-김치`를 추가.
- **세트 상품**: 대표 품목이 체크 안 돼 빠졌지만 걸린 다른 품목은 체크된 주문은 ‘확인 필요’와 점검창(🟡 여러 품목에 걸려 빠진 주문)에 표시.
- **짧은 전화번호 차단**: 숫자 8자리 미만은 ‘전화번호가 너무 짧음’(빨간 칸, 점검창).
- **‘기타’ 빠짐 상시 표시**: 하단 바에 ‘빠짐 N건 (목록에 없는 상품 M건)’.
- **메뉴·포커스**: 열린 메뉴의 태그를 다시 누르면 닫힘, 메뉴가 열린 채 표가 다시 그려지면 품목 칸으로 포커스. 점검창 취소 후 첫 문제 칸으로 포커스. 키보드 안내는 표에 포커스가 있을 때만.
- ② 요약 줄에 해제한 품목 이름 표시(모바일). **데스크톱 ② 접기는 반영하지 않음** — 품목 선택은 사용자가 직접 요청한 핵심 기능이라 데스크톱에서는 늘 보이게 둠.
