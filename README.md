# 발주서 자동 변환기 (Purchase-Order)

스마트스토어·쿠팡 등 오픈마켓에서 내려받은 **주문 엑셀**을 올리면,
공급처에 보낼 **당일발주 양식 엑셀**(`수취자명 / 구입품목 / 수량 / 전화번호 / 주소 / 배송메세지`)로 자동 변환합니다.

- 모든 처리는 **브라우저 안에서만** 이루어집니다. 주문자 개인정보가 서버로 전송되지 않습니다.
- 설치 없이 `index.html`을 브라우저로 열면 바로 사용할 수 있습니다.

## 사용법

1. `index.html`을 크롬/엣지로 엽니다. (또는 `npm start` 후 http://localhost:8080)
2. 스마트스토어/쿠팡 주문 파일(.xlsx/.xls/.csv)을 끌어다 놓습니다. 여러 파일을 한 번에 올릴 수 있습니다.
   - 비밀번호가 걸린 스마트스토어 파일은 비밀번호를 입력하면 브라우저 안에서 바로 열립니다.
3. **발주할 품목**을 체크합니다. 체크한 품목의 주문만 발주서에 들어갑니다.
   - 기본 품목: 수제비, 칼국수, 구포국수, 예산국수, 기장 쪽파, 여수 돌산갓, 청도 미나리, 곡물면
   - `기타` 칸에서 품목을 직접 추가할 수 있고, 목록에 없는 상품을 포함할지도 고를 수 있습니다. (품목 목록은 브라우저에 저장)
4. 미리보기에서 칸을 눌러 바로 고치거나 주문을 빼고, **당일발주 엑셀 다운로드**를 누릅니다.
   - 취소·반품 주문과 중복 주문은 자동으로 빠지며, `제외된 주문도 보기`로 확인·되살릴 수 있습니다.

## 지원 형식

| 마켓 | 사용하는 컬럼 |
| --- | --- |
| 스마트스토어 (발주발송관리) | 수취인명, 상품명 + 옵션정보, 수량, 수취인연락처1(없으면 2), 통합배송지(없으면 기본+상세배송지), 배송메세지 |
| 쿠팡 Wing (배송관리) | 수취인이름, 등록상품명 + 등록옵션명, 구매수(수량), 수취인전화번호, 수취인 주소, 배송메세지 |
| 기타 | 위와 비슷한 이름의 헤더를 자동 인식 |

## 개발

```bash
npm install          # 테스트 도구 설치
npm test             # 단위 + 브라우저(E2E) 테스트
npm run samples      # samples/ 의 가짜 주문 파일 재생성 (python3 + openpyxl, 암호 샘플은 msoffcrypto-tool)
node scripts/screenshot.js v1   # 화면 캡처 → docs/screenshots/
```

## 버전 기록

작성자 1명 + 검증자(기능 테스트) + 평가자(UX/디자인) 에이전트의 피드백 루프로 개선했습니다.
라운드별 피드백과 변경 내용은 [docs/REVIEW_LOG.md](docs/REVIEW_LOG.md)에, 각 버전은 `vN:` 으로 시작하는 커밋과
`docs/screenshots/vN-*.png` 화면 캡처로 비교할 수 있습니다. 앱 상단 배지에도 현재 버전이 표시됩니다.
