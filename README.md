# 발주서 자동 변환기 (Purchase-Order)

스마트스토어·쿠팡 등 오픈마켓에서 내려받은 **주문 엑셀**을 올리면,
공급처에 보낼 **당일발주 양식 엑셀**(`수취자명 / 구입품목 / 수량 / 전화번호 / 주소 / 배송메세지`)로 자동 변환합니다.

- 모든 처리는 **브라우저 안에서만** 이루어집니다. 주문자 개인정보가 서버로 전송되지 않습니다.
  (중복 발주 방지를 위해 최근 14일 발주한 주문의 해시값만 브라우저에 남기며, 화면 아래 `발주 기록 지우기`로 지울 수 있습니다.)
- 설치 없이 `index.html`을 브라우저로 열면 바로 사용할 수 있습니다.

## 실행 방법

설치할 것은 없습니다. 둘 중 편한 방법을 쓰세요.

- **파일 하나로 (가장 쉬움)**: `발주서_자동변환기.html` 한 파일만 받아서 더블클릭하면 크롬·엣지에서 열립니다. 인터넷 없이도 동작합니다.
  (새로 만들기: `python3 scripts/build_artifact.py --standalone 발주서_자동변환기.html`)
- **폴더째로**: GitHub에서 `Code → Download ZIP`으로 받은 뒤 **압축을 풀고**, 폴더 안의 `index.html`을 엽니다. (ZIP 안에서 바로 열면 동작하지 않습니다.)
- **인터넷 주소로**: `python3 scripts/build_artifact.py 출력.html`로 만든 한 장짜리 페이지(+ `vendor/` 파일)를 어디에 올려도 됩니다.

## 사용법

1. **주문 파일 올리기** — 스마트스토어/쿠팡 주문 파일(.xlsx/.xls/.csv)을 끌어다 놓거나 `파일 선택`. 여러 파일을 한 번에 올릴 수 있고, 비밀번호가 걸린 파일은 비밀번호를 입력하면 브라우저 안에서 바로 열립니다.
2. **발주할 품목 입력** — 입력칸에 `수제비, 칼국수, 청도 미나리`처럼 쉼표로 나눠 적으면, 상품명에 그 글자가 들어 있는 주문만 발주서에 들어갑니다. 비워 두면 전체 주문이 들어갑니다. 적는 즉시 품목별 건수가 보이고, 적은 내용은 다음에도 남아 있습니다.
3. **확인 후 다운로드** — 칸을 눌러 바로 고치거나 주문을 빼고 `당일발주 엑셀 다운로드`.
   - 취소·반품·이미 발송된 주문, 중복 주문, **지난 14일 안에 이미 발주한 주문**은 자동으로 빠지며, `빠진 주문` 탭에서 확인하고 맨 앞 체크로 되살릴 수 있습니다.
   - 빈 칸·오류·중복 의심이 있으면 다운로드 전에 한 번 더 확인합니다.
4. 다운로드 후 안내에 따라 공급처에 파일을 보내고, 쇼핑몰에서 발주확인(발송처리)을 합니다.

### 품목 입력 요령

| 이렇게 적으면 | 뜻 | 예 |
| --- | --- | --- |
| `수제비, 칼국수` | 쉼표로 여러 품목 (띄어쓰기 무시) | `감자 수제비 500g`, `생칼국수 1kg` |
| `청도 미나리` | 띄어 쓴 단어가 모두 들어 있는 주문 | `[청도] 미나리 1kg`, `미나리 (경북 청도산)` (O), `돌미나리` (X) |
| `쪽파 -찰기장` | `-` 붙인 단어가 있으면 제외 | `찰기장 쪽파전 믹스` (X) |

## 지원 형식

| 마켓 | 사용하는 컬럼 |
| --- | --- |
| 스마트스토어 (발주발송관리) | 수취인명, 상품명 + 옵션정보, 수량, 수취인연락처1(없으면 2), 통합배송지(없으면 기본+상세배송지), 배송메세지 |
| 쿠팡 Wing (배송관리) | 수취인이름, 등록상품명 + 등록옵션명, 구매수(수량), 수취인전화번호, 수취인 주소, 배송메세지 |
| 기타 | 위와 비슷한 이름의 헤더를 자동 인식 |

## 개발

```bash
npm install          # 테스트 도구 설치
npm test             # 단위 + 브라우저(E2E) 테스트
npm run samples      # samples/ 의 가짜 주문 파일 재생성 (python3 + openpyxl, 암호 샘플은 msoffcrypto-tool)
node scripts/screenshot.js v1   # 화면 캡처 → docs/screenshots/
```

## 버전 기록

작성자 1명 + 검증자(기능 테스트) + 평가자(UX/디자인) 에이전트의 피드백 루프로 개선했습니다.

`docs/screenshots/vN-*.png` 화면 캡처로 비교할 수 있습니다. 앱 상단 배지에도 현재 버전이 표시됩니다.
