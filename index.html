① 주문 파일 올리기

📄

스마트스토어·쿠팡 주문 엑셀을 여기에 끌어다 놓거나아래 버튼을 눌러 주문 엑셀을 고르세요

.xlsx · .xls · .csv · 여러 파일 한 번에 가능 · 비밀번호 걸린 파일도 OK

주문 파일은 어디서 받나요?
  • 스마트스토어: 스마트스토어센터 → 판매관리 → 발주(주문)확인/발송관리 → 엑셀다운
    다운로드할 때 정한 비밀번호가 있으면 올린 뒤 입력하면 됩니다.
  • 쿠팡: 쿠팡 Wing → 주문/배송 → 배송관리 → 엑셀 다운로드
  • 기타 쇼핑몰: 수취인·상품명·수량·전화번호·주소 열이 있는 엑셀이면 자동으로 인식합니다.

파일을 읽는 중…

    ② 발주할 품목 고르기

    체크한 품목의 주문만 발주서에 들어갑니다. 상품명에 품목 이름이 들어 있으면 자동으로 분류됩니다.

    ③ 확인 후 다운로드

    주문 파일을 올리면 여기에 발주서 미리보기가 나타납니다.

    칸을 눌러 내용을 바로 고칠 수 있습니다. 맨 앞 체크를 끄면 그 주문은 발주서에서 빠집니다.

    엑셀을 받을 때 정한 비밀번호를 입력해 주세요.
