① 주문 파일 올리기

📄

스마트스토어·쿠팡 주문 엑셀을 여기에 끌어다 놓거나아래 버튼을 눌러 주문 엑셀을 고르세요

파일을 더 끌어다 놓거나

.xlsx · .xls · .csv 파일을 여러 개 한 번에 올릴 수 있고, 비밀번호가 걸린 파일도 열 수 있습니다.

주문 파일은 어디서 받나요?
  • 스마트스토어: 스마트스토어센터 → 판매관리 → 발주(주문)확인/발송관리 → 엑셀다운
    다운로드할 때 정한 비밀번호가 있으면 올린 뒤 입력하면 됩니다.
  • 쿠팡: 쿠팡 Wing → 주문/배송 → 배송관리 → 엑셀 다운로드
  • 기타 쇼핑몰: 수취인·상품명·수량·전화번호·주소 열이 있는 엑셀이면 자동으로 인식합니다.

파일을 읽는 중…

    ② 발주할 품목 고르기

    체크한 품목의 주문만 발주서에 들어갑니다. 상품명에 품목 이름(또는 키워드)이 들어 있으면 자동으로 분류됩니다.

    ⚠ 이 브라우저에서는 품목 설정을 저장할 수 없어, 다음에 열면 기본 품목으로 돌아갑니다. (시크릿 창이거나 저장 공간이 막혀 있을 수 있습니다.)

    품목 관리

    품목 이름은 항상 키워드로 쓰이고, 아래에 추가 키워드를 쉼표로 넣을 수 있습니다. 띄어쓰기는 무시합니다.
    A+B 는 A와 B가 둘 다 들어 있을 때만 해당합니다. 예) 청도+미나리 → ‘[청도] 미나리 1kg’ 인식, ‘돌미나리’는 제외

      ③ 확인 후 다운로드

      주문 파일을 올리면 여기에 발주서 미리보기가 나타납니다.

      칸을 누르면 바로 고칠 수 있고, 맨 앞 체크를 끄면 그 주문은 빠집니다. (키보드: 방향키 이동 · Enter 고치기 · Esc 취소)

      발주 포함 수취자명 구입품목 품목 수량 전화번호 주소 배송메세지 되돌리기
